# Project Vision

BinRun makes bin day hassle-free for households, property owners, and short-term
rental hosts in Whangarei.

The MVP should let customers manage properties, select a clear service package,
track collection schedules, and maintain an active subscription without needing
to understand waste-provider logistics. BinRun handles bin movement and optional
cleaning only; council and third-party providers remain responsible for waste
collection.

The public product language is package-led:

- Regular Run: weekly set-out and return for one service address.
- Regular Run + Wash: weekly set-out and return with scheduled bin cleaning.
- One-Off Clean: a single cleaning visit without a subscription.
- Custom Package: tailored service for multiple properties, blocks of flats,
  body corporates, landlords, or larger sites.

Self-serve signup is not the only path. The site should clearly invite customers
to email BinRun for assisted setup, especially for seniors or anyone who does not
want to sign up online.
