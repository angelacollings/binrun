# BinRun UI Mockups

## Overview

These mockups represent the initial design direction for BinRun.

- Modern, minimal UI
- Adaptive to light/dark mode (via system settings)
- Accessible contrast
- Earthy color palette (green, maroon, blue accents)

---

## Screens Included

- Homepage
- Dashboard
- Pricing Page
